# v100 target inventory (M0 probe, 2026-10-31)

Generated by `tools/volta/scaffold_target_dirs.sh`, which mirrors every
`rtx5090/` and `dgx_spark/` source directory with a placeholder `v100/` twin.
Result: **189 placeholder files (143 `.cu`/`.cuh` + 46 `sources.cmake`)** and
`cmake --preset v100-release` configures clean on CUDA 12.9.1 (first pass had
16 missing-include errors). This file lists what each placeholder represents
and where the Volta implementation comes from.

Leaf filenames of upstream's per-target files and of geoffwatts' Volta kernels
have **zero overlap** — the transplant is function-by-function into upstream's
interface conventions, not a path rename.
